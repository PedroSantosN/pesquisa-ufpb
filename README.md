 🎮 Como executar o jogo

Para jogar, siga os passos abaixo:

1. **Baixe** os arquivos do projeto para o seu computador.
2. **Extraia** o conteúdo do arquivo compactado (`.zip`).
3. Abra a pasta extraída.
4. **Execute o arquivo `index.html`** no seu navegador de preferência.

Pronto! Agora é só jogar e se divertir! 🚀
